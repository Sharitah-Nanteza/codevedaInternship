# Sharitah Custom Component Library Documentation

A highly accessible, performance-optimized, and reusable custom component library built with React, TypeScript, and Vite.

## Components

### 1. Button Component
A reusable custom button styled and structured for high interactivity and performance.

#### Usage
```tsx
import { Button } from '@nanteza/sharitah-custom-components';

function App() {
  return (
    <Button onClick="{()"> console.log('Clicked!')}>
      Click Me
    </Button>
  );
}
